## 📌 主な変更点
- 新しい環境変数とコマンドを追加。`CLAUDE_CODE_DISABLE_WEB_FETCH`でWebFetchツールを無効化でき、`claude --desktop`でClaudeデスクトップアプリを開けます。`claude plugin configure`ではプラグインのオプションを確認・設定できます。
- 管理設定に`allowedProviders`を追加し、マシンで使えるAPIプロバイダー（Anthropic API、Bedrock、Vertex AIなど）を制限できるようになりました。
- `/resume`と`claude --resume`が、バックグラウンドで実行中のセッションを開けるようになりました。`claude --resume <id> "prompt"`で渡したプロンプトは、そのセッションの次のターンとして送られます。
- 動作の変更。バックグラウンドのBash/PowerShellコマンドに時間制限（デフォルト30分、最大2時間）が付きました。カスタム`ANTHROPIC_BASE_URL`経由のセッションでは、対応モデルの1Mコンテキストウィンドウを使います。`/ultrareview`のアップロード要件も変わり、macOSとLinuxではgit 2.31以降が必要です。
- 多数の不具合を修正。プラグインのSSHインストール、MCPサーバー一覧（`ws`対応）、サブエージェントの権限モード、フック、Artifactツール、`/ultrareview`のアップロード、VSCode拡張の各種問題などが含まれます。サンドボックス設定では、プロジェクト設定が管理者設定を緩められないようにもなりました。
