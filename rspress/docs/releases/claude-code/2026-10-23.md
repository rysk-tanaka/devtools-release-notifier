## 📌 主な変更点
- サンドボックスとセキュリティを強化。シェル起動ファイルがサンドボックス外で実行される問題、macOSの denyWrite パターンがシンボリックリンク経由で効かない問題、--mcp-config のファイルが変更可能だった問題を修正

- ctrl+enter（今すぐ送信）、/rewind、/privacy-settings、/feedback など多数の操作性のバグを修正。Windowsでの git コマンドも高速化
- VS Code拡張、クラウドセッション、Claude Tag（Slack）、Code Review に関する修正を多数含む
