- 新しい環境変数を追加: `CLAUDE_CODE_DISABLE_ULTRATHINK`（ultrathinkキーワードを無効化）、`CLAUDE_CODE_SUBAGENT_EFFORT`（サブエージェントのエフォートレベルを指定）、`CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP`（相互認証されたシステム証明書を保持）
