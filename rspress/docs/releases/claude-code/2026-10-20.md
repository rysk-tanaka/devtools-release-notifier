## 📌 主な変更点
- `/auto-mode-setup` を追加。プロジェクトや直近のセッションを読み取り、auto modeに環境を学習させる対話式セットアップで、Bedrock、Vertex、Foundryなどでも利用可能
- `/claude-api managed-agents-secure` を追加。Managed Agentsの設定をAnthropic公開のセキュリティガイドと比較（変更は行わない）
- modのフック関連を強化。`tool.check` に `decider: "person"` と `e.isReadOnly` を追加し、`settings.read` フックは各設定レイヤーを受け取りマージ後の設定を書き換え可能に
- Linuxのサンドボックスで `denyRead` のglobに角括弧が含まれると起動に失敗する問題や、`rm -r` でマウント済みドライブ等に安全確認が出ない問題を修正
- `claude --worktree` が終了時に確認なしでworktreeとブランチを削除し、コミットを失う可能性があった問題を修正。ツール検索はカスタム `ANTHROPIC_BASE_URL` 配下でもデフォルトで有効化
- 多数のサブエージェント実行時の応答性・スループットや、長い会話でのメモリ使用量を改善
