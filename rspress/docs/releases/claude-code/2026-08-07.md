## 📌 主な変更点
- セルフホスト環境機能を追加。`claude self-hosted-runner` で自前のマシンやコンテナ上でweb/モバイル/デスクトップセッションを実行可能に（Team/Enterpriseプラン）

- Remote Controlの接続失敗表示や再接続導線、圧縮処理中の進捗表示を改善
- 1セッションあたり200サブエージェントというスポーン上限を撤廃
