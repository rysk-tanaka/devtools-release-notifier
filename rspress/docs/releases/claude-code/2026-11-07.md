## リリースノート

## 📌 主な変更点
- MCPタスクのターミナル対応を追加。MCPサーバーがタスクとして実行したツール呼び出しは即座にバックグラウンドへ移り、完了時に結果がClaudeへ通知される（`CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND` で待機動作に変更、`CLAUDE_CODE_DISABLE_MCP_TASKS=1` で無効化）
- 新設定 `permissions.denyInsteadOfPrompting` を追加。許可プロンプト待ちになるツール呼び出しを拒否してターンを継続する
- `CLAUDE_CODE_DISABLE_FEATURE_FLAGS` を追加。テレメトリを止めずにフィーチャーフラグの取得だけを停止できる。あわせて、テレメトリやフラグが無効なauto modeでは、サーバーで確認できない呼び出しは確認または拒否されるよう変更（`CLAUDE_CODE_AUTO_MODE_SERVER=0` で従来の分類器を継続利用可）
- セキュリティ修正。細工した環境変数プレフィックスによるBash権限チェックの回避、クォートされた語を含むコマンドでのdeny/askルールの取りこぼし、`sed` の権限チェックのスキップ、worktree作成時のサンドボックス脱出、`/rewind` がディレクトリのシンボリックリンク経由でファイルを復元・削除する問題を修正
- 新コマンド `/claude-api latency-optimize` を追加。`/tasks` に完了済みサブエージェントの「Earlier in this session」欄を追加。`/diff` の不具合（`HEAD` という名前のファイルやフォルダがある場合など）、`/context` の出力の簡素化、`/model` ピッカーの「More models」グループ化も実施
