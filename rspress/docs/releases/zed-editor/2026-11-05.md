## 📌 主な変更点
- Gitの自動フェッチ機能を追加（デフォルトは無効）。`git.auto_fetch.enabled`で有効化し、`git.auto_fetch.interval_secs`で間隔を設定可能（デフォルト60秒）
- Git Graphにサイズ変更可能な「Refs」列を追加し、Git Panelからターミナルやエディタペインへのファイルのドラッグにも対応
- `mouse_wheel_zoom`有効時に、diffビューとターミナルでマウスホイールによるフォントズームに対応（macOSは`cmd-scroll`、Linux/Windowsは`ctrl-scroll`）
- AI関連の改善：最新のAgent Client Protocolへの互換性向上、`read_file`ツールで2,000文字超の行を切り詰めてコンテキストオーバーフローを防止、ステータスバーの編集予測ボタンを切り替える`edit_predictions.button`設定を追加
- 多数のバグ修正：Tree-sitterハイライト失敗時のクラッシュ、Vimビジュアルブロックモードのハング、リモートワークスペース関連の問題、Forgejo/Codebergでのプルリクエスト作成、Windows関連の不具合など
